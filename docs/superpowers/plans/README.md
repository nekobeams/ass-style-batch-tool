# 實作計畫(歷史記錄)

這個資料夾放的是**已經實作完成**的功能實作計畫,依日期命名。它們是開發
過程的記錄,不是使用說明,也不是目前架構的權威描述。

**想找什麼看哪裡:**

| 你想知道 | 去看 |
|---|---|
| 這個工具怎麼用 | [README.md](../../../README.md) |
| 每個版本改了什麼 | [CHANGELOG.md](../../../CHANGELOG.md) |
| 目前的設計與架構決策 | [../specs/](../specs/) |
| 某個功能當初為什麼這樣設計 | 本資料夾對應日期的計畫 |

**為什麼留著:** 這些計畫裡記錄了不少從程式碼本身讀不出來的東西——核心
不變式、當初評估過但沒採用的做法、以及某些寫法背後的理由。例如樣式掃描
的「掃描結果只能是資訊,不能替使用者做刪除決定」這條不變式,只寫在計畫
裡;不知道的人很容易在重構時把它破壞掉。

**注意:** 計畫內容反映的是**撰寫當下**的狀態,後續版本可能已經改變。以
程式碼與 `specs/` 為準。
